# Face Emotion Recognition 😃🎭

A real-time **Face Emotion Recognition System** built using **Python, OpenCV, and Deep Learning**.
This project detects human faces through a webcam/video stream and predicts emotions such as **Happy, Sad, Angry, Surprise, Neutral, Fear, and Disgust** in real time.

Facial Emotion Recognition (FER) is widely used in **AI, Computer Vision, Human-Computer Interaction, Healthcare, Security, and Smart Applications**. ([GitHub][1])

---

## 🚀 Features

* 🎥 Real-time face detection using webcam
* 😀 Emotion prediction from facial expressions
* 🧠 Deep Learning based emotion classification
* 📦 OpenCV integration for image processing
* ⚡ Fast and lightweight implementation
* 📊 Supports multiple emotion classes

---

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/arunvithushan/Face-Emotion-Recognition.git
cd Face-Emotion-Recognition
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

```bash
python emotion_detection.py
```

The webcam will open and start detecting faces and emotions in real time.
